Local refresh runbook

  1. In propertyiq_getdata: 
    uv run propertyiq-getdata rentboard export-legacy --data-dir data
    uv run propertyiq-getdata nswgov export-legacy --data-dir data
  2. Copy both CSVs into data-qa-agent/data/ (gitignored).
  3. Regenerate the committed samples so CI + make up stay fast: 
    make samples
  4. Rebuild raw → staging → marts against the full files: 
    make pipeline-full   # PIPELINE_SOURCE=full
    Plain make pipeline uses the small samples — it will not pick up new volume.
  5. Verify end to end: make smoke

Cloud (AWS) refresh

  1. Upload the two CSVs to the source-data bucket (DATA_S3_BUCKET, wired in infra/terraform/foundations/ecs.tf). no script exists
  2. Authenticate: aws sso login --profile data-qa
  3. Run the one-shot ECS Fargate job: 
    ./scripts/run_job.sh pipeline
    dlt streams each object straight from S3 — no 580 MB local download.
  4. Smoke the deployed stack: ./scripts/cloud_smoke.sh

Dataset registry + RLS grants live in config/datasets.yaml; the seed's source of truth is Alembic migration 0002_property_market.
